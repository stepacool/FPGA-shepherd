# Tang Nano 9K

Sipeed Tang Nano 9K is a small FPGA board based on the Gowin GW1NR-9 (GW1NR-LV9QN88PC6/I5).

- On-board 27 MHz oscillator (typically pin 52)
- Six user LEDs (active low)
- USB-JTAG via FTDI for programming (SRAM or flash)
- Shepherd board name: `tangnano9k`

Official wiki: https://wiki.sipeed.com/hardware/en/tang/Tang-Nano-9K/Nano-9K.html
